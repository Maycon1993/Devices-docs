Based on local video playback test. Testing conducted by Microsoft in January 2025 using preproduction software and preproduction Surface Laptop 13" Intel Core Ultra 5 256GB, 16GB RAM devices and Surface Laptop 15" Intel Core Ultra 7 256GB, 16GB RAM devices. Testing consisted of full battery discharge during video playback of a .mov file through the Windows Media Player application in 1080p at 24 FPS. All settings were default except screen brightness set to 150 nits with Autobrightness disabled. Wi-Fi was connected to a network. Battery life varies significantly with settings, usage, and other factors.

All settings were default except screen brightness set to 150 nits with Auto-Brightness disabled. Wi-Fi was connected to a network.
