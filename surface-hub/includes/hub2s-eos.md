> [!IMPORTANT]  
> Support for Surface Hub 2S devices running Windows 10 Team edition ends on **October 14, 2025**. To avoid service disruption, we recommend using the seamless **[software migration](/surface-hub/surface-hub-2s-migrate-to-mtr-w)** option to move to Microsoft Teams Rooms on Windows at any time before the end of support.  
>  
> Unlike the standard versions of Windows 10, there's no extended support option for Windows 10 Team edition when support ends.
